# Prototype Flows

## Primary conversion flow
Onboarding -> Home -> Capture Meal -> AI Analysis -> Edit -> Save Meal -> Nutrition Summary -> Trends

## Subscription upsell flow
Diet Plans Locked Banner -> Pricing (₹) -> Method Select -> Razorpay/PhonePe Flow -> Success -> Unlocked Plans

## Retention flow
Home Reminder -> Step Tracker -> Achievement Earned -> Share to Community

## Error recovery flow
AI Fail (No Food Detected) -> Retake / Manual Entry -> Save
Payment Fail -> Retry / Change Method -> Success

## Interaction notes
- Swipe day cards in trends and diet weekly planner.
- Long-press step ring to edit daily goal.
- Tap chart points for exact values.
- Snackbar after save/update actions.
