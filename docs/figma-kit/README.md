# FitLens / Fitola Figma Download Kit

This folder is a **Figma-ready handoff package** you can import or rebuild quickly.

## What's included
- `design-tokens.json` — Color, spacing, typography, radius, shadows, breakpoints.
- `components.csv` — Component catalog and variant naming conventions.
- `screens.csv` — Complete screen inventory for Web + Mobile.
- `prototype-flows.md` — End-to-end prototype flow map.
- `figma-build-checklist.md` — Step-by-step guide to build and export all screens from Figma.

## How to use in Figma
1. Create pages:
   - `01_DesignSystem`
   - `02_Wireframes`
   - `03_HighFidelity/Mobile`
   - `04_HighFidelity/Web`
   - `05_Prototypes`
   - `06_Subscription`
   - `07_DietPlans`
2. Import `design-tokens.json` into your token plugin (Tokens Studio or equivalent).
3. Build components from `components.csv` using Auto Layout.
4. Build all screens from `screens.csv`.
5. Connect interactions from `prototype-flows.md`.
6. Export screens as PNG/PDF from Figma.

## Payment gateways and INR
All subscription/payment screens are defined with Indian currency (₹) and include:
- Razorpay card checkout
- UPI Autopay flows (PhonePe + other UPI apps)
- Billing history and mandate/error states

## Notes
This kit is implementation-oriented and avoids placeholder-only mockups.
